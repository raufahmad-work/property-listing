# property-listing
To find Addresses from Zillow and Street Easy


Steps to run this Project:

1. Install Python 3.9.
2. Make virtual environment inside the root directory using command: python -m venv venv
3. Activate cirtual environment using command: source venv/bin/activate
4. Install the requiremens usign command: pip install -r requirements.txt
5. Make a .env file in root directory
6. Add you env variables values in it. (See .env.example for the required env variables)
7. You can now run the script using command: python -m script.script
